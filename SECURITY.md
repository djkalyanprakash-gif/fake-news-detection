# Security Policy

## Reporting a vulnerability

If you find a security problem in this project, please open a GitHub issue and describe it briefly. Do not post sensitive details, exploit code, or anyone's personal data in the issue — just enough for me to understand and reproduce the problem. I will look into it and fix it as soon as I can.

## What this repo contains

This repository contains no secrets, tokens, passwords, API keys, or personal data. The only personal details in it are the author's name and public GitHub and LinkedIn profile links.

The app itself does not collect or store anything you paste into it. Articles are processed in memory only, there is no login, no analytics, and no tracking. See the Privacy & Security section in the README for details.
